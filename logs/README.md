# LLM logs

The assignment asks for the conversations you had with LLMs, uploaded as a zip.

## What to include

- Every conversation that shaped the brief or the prototype, exported from the chat tool you used (a shared link, a PDF or a copied transcript).
- One file per conversation, named by date and topic, for example `2026-11-03_problem-scoping.pdf`.
- A short `index.md` listing each file and what it was used for, so a reviewer can find the key prompts quickly.

## What not to do

- Do not edit, trim or rewrite the transcripts. Reviewers use them to see your own thinking, so altered logs defeat their purpose.
- Do not include another person's conversations as your own.

## This example

`session_log.md` indexes the real conversation that produced this template: the user's prompts verbatim and a summary of what the assistant did in each turn. It is a summary, not the full transcript.
